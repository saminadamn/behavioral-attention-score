🔎 Adversarial Case Audit

What we actually checked the scoring engine against

Rather than only trusting the synthetic-dataset statistics, we constructed specific adversarial cases — each one isolating a single behavioural pattern — and checked whether BASEngine's score moved the way that pattern implies. This is the same methodology used to clinically stress-test the companion live classifier in ADHD-behavioral-attention-score, applied here to this repository's own scorer. Full writeup: docs/ROBUSTNESS_AUDIT.md.

📋 After the summer project

Survey-question validation — the live classifier, not this repo's simulator

This repo (and the summer Minor Project it came from) only ever scores a synthetic dataset. The follow-on work — done after the summer project, on the separate live ADHD-behavioral-attention-score classifier — went further: ten classroom turns were hand-written, each embodying one item from a standard 50-item clinical ADHD assessment instrument (DSM-5-TR / ASRS-style inattention and hyperactivity-impulsivity items, plus Barkley BDEFS executive-function and emotional-regulation items), and run through that classifier end-to-end as one continuous session, BAS and attention-state memory carried across turns the way a real session would be.

Two of these ten cases failed on the first run and drove real fixes — Q4 and Q17/Q10 originally misclassified as Focused with a positive reward (the worst failure mode: raises BAS and withholds the intervention), which is what led to the repetition_score / completeness_score signals, and Q16 exposed the latency-vs-question-complexity gap that led to prematurity_score — the table above is the result after those fixes, not the original run. Full detail, per-turn interventions, and the reproduce command are in docs/questionnaire_validation.md and docs/model_limitations.md in that repo; the same ten cases are regression-tested in backend/tests/test_questionnaire_constructs.py.

Not a validation study against the questionnaire itself. The classifier takes one classroom turn (prompt + response + latency), not a 50-item self-report, and a single turn can't establish onset, cross-setting presence, or impairment — what an actual clinical assessment measures. These cases were hand-constructed to embody one construct each, specifically so a gap between what the construct implies and what the pipeline's behavioural signals can see from text alone would show up as a mismatch.

The second row is the actual finding: abs_normalized_latency only compares a response's speed to that same student's own history, so it had no way to tell "fast for this student" apart from "implausibly fast for this question." We added prompt_relative_latency — latency expressed as a multiple of the prompt's own reading time — as an 11th weighted feature. The third row is a control: a pattern that was already handled correctly (by the existing coherence / repetition_ratio weighting), included here so the audit isn't reporting only the failure it found.

Ablation study — what each part of the engine is actually worth

Freshly re-run against the current (post-fix) engine using AblationRunner (Module 13): one baseline run, then one run per row with exactly that piece zero-weighted and everything else held fixed — 30 students × 3 sessions, seed 42, 9,102 records.

Ablation What's zero-weighted Metric Baseline Ablated Reading
learning_response features correctness, semantic_similarity, coherence, lexical_diversity, confidence BAS mean 0.7436 0.7350 −0.0086 — these carry real weight; removing them lowers the score
behaviour features hesitation, topic_shift, repetition_ratio, fatigue, abs_normalized_latency, prompt_relative_latency BAS mean 0.7436 0.7507 +0.0071 — these are negative-polarity penalties; removing them raises the score, as expected
temporal smoothing EMA smoothing → IDENTITY (raw score, unsmoothed) BAS mean 0.7436 0.7365 −0.0072 — smoothing measurably changes the aggregate, not just per-interaction noise
confidence weighting confidence_variance_weight, confidence_classifier_weight → 0 BAS mean 0.7436 0.7436 no change — by design: classifier_confidence is zero-weight unless a trained predictor is injected
reward: performance correctness/accuracy-derived reward signals avg reward −0.0039 −0.0060 −0.0021 — the largest single reward-category effect measured
reward: cost intervention-cost penalty avg reward −0.0039 −0.0016 +0.0023 — removing a penalty raises average reward, as expected
intervention cooldown cooldown spacing + duplicate-prevention window interventions executed 1,217 1,435 +218 (+17.9%) — cooldown is doing real throttling work, not a no-op safeguard

The point of an ablation table is as much about what doesn't move as what does — the confidence-weighting row is correctly a no-op here because that signal is opt-in and off by default, not a bug in the ablation itself. Full category/policy ablation (reward categories, intervention policies) and the reward-weight and need-threshold sensitivity sweeps are in docs/APPENDIX_ANALYSIS.md, reproducible via run_appendix_analysis.py.

Offline-RL comparison — does a learned policy agree with the logged one?

Freshly re-run via run_comparison_study.py (20 students × 3 sessions, seed 42): eight agents trained offline on the same logged rule-based-policy dataset, then measured against the one metric that's actually valid offline — how often the trained policy's greedy action agrees with the logged action, not a re-simulated causal reward (see the caveat below).

Agent Family Final loss Greedy/logged agreement Train time
Vanilla DQN unconstrained online-style 0.0038 0.0219 0.64s
Double DQN unconstrained online-style 0.0065 0.0153 0.72s
Double DQN + PER unconstrained online-style 0.0036 0.0482 1.01s
DRQN (+ PER + LSTM) unconstrained online-style 0.0050 0.0389 2.69s
IQL (τ=0.7) offline-specific 0.0016 0.0241 3.87s
CQL (α=1.0) offline-specific, conservative 0.0931 0.8796 3.16s
Discrete BCQ (τ=0.3) offline-specific, conservative 0.0021 0.8643 3.61s

CQL and BCQ — the two agents explicitly built to penalize actions far from the logged behaviour — agree with the logged policy on roughly 86–88% of actions, against 1.5–4.8% for the unconstrained DQN family. That gap is the actual evidence for "conservative offline methods avoid extrapolating to actions the data never showed," not an assumption. One honest wrinkle: IQL — also designed for offline data — agrees only 2.4% of the time here, about the same as plain DQN, so "offline-specific" alone doesn't predict this outcome; the conservatism mechanism (explicit penalty in CQL/BCQ vs. implicit expectile regression in IQL) appears to matter more than the offline/online label.

Caveat, stated plainly: avg_reward_logged_dataset is identical across every row (−0.0033) because none of these algorithms regenerates sessions — it's the same observed reward replayed, not a causal per-policy reward. Loss and greedy/logged agreement are the real, per-algorithm numbers here. A genuine causal comparison would need each policy to actually drive new sessions, which is what Phase 2's baseline comparison (Rule-Based vs. No-Intervention vs. Random, all causal) does instead — see docs/OFFLINE_RL.md for the full discussion of why offline agreement and causal reward are different questions.

The companion classifier comparison (Logistic Regression / Random Forest / MLP / LSTM) all scored a perfect 1.0 accuracy and F1 on this run — expected and not a strong result on its own, since the classifier is trained to recover the generator's own labeling rule from fully observable features, not to diagnose anything in the real world (see docs/DEEP_LEARNING_COMPARISON.md).

What this is not

This is a software-robustness audit of a synthetic-data scoring engine, not a clinical validation study. The three cases above are hand-constructed, not drawn from a real assessment instrument — the project that stress-tests against an actual clinical questionnaire is the separate ADHD-behavioral-attention-score live classifier (linked above), whose own questionnaire_validation.md documents that work. The weight split used in the fix (0.12 new / 0.02 old / 0.06 hesitation) is a reasoned engineering choice, not fit to any ground truth.
